# Job & Recruitment Management System

A full-stack job portal designed to connect candidates and recruiters through a structured recruitment platform.

The project is being built to understand and implement real-world backend and frontend concepts using **Node.js, Express.js, MongoDB, Mongoose, and React**.

## Key Features

* User registration and login
* JWT-based authentication
* Role-based authorization
* Candidate and recruiter profiles
* Job creation and management
* Job search and filtering
* Pagination
* Job applications
* Saved/bookmarked jobs
* Company management
* Resume upload
* Application status tracking
* Notifications
* Recruiter dashboard
* Admin management
* Centralized error handling
* Request validation
* API security and best practices

## Tech Stack

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT
* bcrypt
* REST APIs

### Frontend

* React.js
* JavaScript / TypeScript
* Axios

### Development

* Git & GitHub
* Nodemon
* Environment variables
* Postman

## Project Goal

The main goal of this project is to build a production-style application while gaining practical experience with backend architecture, REST API development, authentication, database design, MongoDB queries, relationships, middleware, validation, error handling, and frontend-backend integration.
